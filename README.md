# Electric Heater Calculator PWA v2.0

## Upload to GitHub

Delete the old repository files, then upload **all contents of this ZIP** to the repository root:

- index.html
- 404.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- robots.txt
- VERSION.txt
- icons/

GitHub Pages setting:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

After deployment, open:

https://nguyentrongngoc22-eng.github.io/EH_calculator/?v=2.0.0

On Android Chrome, clear the old site data once before testing:
Chrome > Settings > Site settings > All sites > nguyentrongngoc22-eng.github.io > Clear & reset.

Then reload the page and use **Add to Home screen** or the app's **Install app** button.
