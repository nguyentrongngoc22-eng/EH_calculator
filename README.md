# Electric Heater Calculator PWA v1.1

## Files to upload
Upload all files and the complete `icons` folder to the root of the GitHub repository.

## GitHub Pages
1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Select branch **main** and folder **/root**.
4. Save and wait for deployment to complete.
5. Open the GitHub Pages URL in Chrome.

## Android installation
Open the GitHub Pages URL in Chrome. Use the **Install app** button or Chrome menu → **Add to Home screen / Install app**.

## Updating an existing installation
After uploading a new version, open the app while online. When **Update app** appears, tap it. If the old version remains cached, clear the site's stored data once and reopen it.

## Required root structure
- index.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- VERSION.txt
- README.md
- icons/
